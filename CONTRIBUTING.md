# Contributing

Use issues to report documentation problems and reproducibility questions. Include the repository commit and a minimal synthetic example when relevant. Never include patient records, private clinical outputs, credentials, or internal deployment details.

Changes to study methods must identify whether they correct historical documentation, restore original code, or introduce a new implementation. Cite source evidence and keep experiment versions separate.

Before proposing runnable instructions, test them against the named code, environment, and artifacts. Keep technical validation separate from clinical claims. Software licensing is pending; rights must be confirmed before importing third-party code or model artifacts.
