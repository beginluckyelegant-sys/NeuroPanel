# NeuroPanel

用于神经科大语言模型辅助诊断研究的代码与复现材料仓库。

[English](README.md) · [复现指南](docs/reproducibility.md) · [模型说明](MODEL_CARD.md)

## 当前状态

已提供仓库文档、配置模板、参数文件清单模板、返修阶段单模型对照的英文提示词，以及不含患者信息的输入格式示例。

**当前版本仅用于整理复现材料，还不能运行 NeuroPanel 或复现论文结果。** 原试验代码、多智能体提示词、依赖环境、评价程序和校准记录仍需核对后补入。模型权重、adapter 和分词器文件安排在最后阶段上传。

## 完善顺序

1. 整理仓库结构和材料说明。
2. 导入原试验代码，核对模型加载、检索、多智能体、critic、修正与投票的实际实现。
3. 补入完整提示词、真实推理配置、环境依赖和模型比较评价程序。
4. 完成不含患者信息的运行示例及测试。
5. 最后上传模型参数与必要加载文件，记录版本和校验值，验证后形成可引用的发布版本。

配置中的 `null` 表示尚未核实，不是运行默认值。返修单模型对照与原试验完整 NeuroPanel 流程分开标注；新增重建代码也应明确其身份。

## 内容导航

- `configs/`：待填写的试验配置模板。
- `prompts/`：现有提示词及其适用范围。
- `src/`：待导入的原试验代码。
- `evaluation/`：评价所需材料与判定规则说明。
- `examples/`：仅演示文件结构的合成输入。
- `weights/`：最后阶段的参数发布清单。
- `docs/`：复现指南、数据开放说明和发布清单。

患者病例、私有输出和部署日志未公开。软件许可证及正式论文引用信息待确认；当前不宣称已提供完整开源实现或临床可用系统。
