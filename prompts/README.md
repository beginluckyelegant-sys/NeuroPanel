# Prompt provenance

`reference/` contains newly written prompts used by the runnable reference architecture; their provenance is the October 2026 reconstruction. They request structured JSON and concise evidence summaries.

`revision_single_model_comparator.txt` preserves the previously supplied revision-stage single-model prompt without modification. The reference runner does not use it; its three-section output contract differs from the new four-section structured contract. Prompt inventories distinguish experiment-specific templates.
